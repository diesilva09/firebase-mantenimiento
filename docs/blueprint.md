# **App Name**: Maintenance Hub

## Core Features:

- Task Scheduler: Schedule maintenance tasks with alerts, including assigning priority and responsibles. Includes future, pending, and completed categories.
- Form System: A form system to generate different types of forms, including selection menus and dropdowns.
- Form Submission Storage: A database system to save and organize form submissions for maintenance and inspections.
- Calendar View: View tasks in a calendar format with color-coded statuses and priorities.
- Task Completion: Mark tasks as complete and log performed work details.
- Spec Sheet Modal: Ability to create and read specifications sheets for the equipment and display on demand
- Dashboard Analytics: Statistical visualization of submitted data through charts, including tracking active users. 

## Style Guidelines:

- Primary color: A calming light blue (#89BBEF), evocative of clean, well-maintained machinery and a sense of reliability.
- Background color: A very light blue (#E5F3FF), which subtly emphasizes the primary color while providing a clean backdrop.
- Accent color: A contrasting dark-blue/indigo (#4A639A) for emphasis on interactive elements.
- Body text: 'PT Sans' (sans-serif) offers a modern and warm style suitable for both headlines and body text, aiding readability in forms and calendar views.
- Code font: 'Source Code Pro' for displaying code snippets within form definitions, when applicable.
- Use clean, professional icons that clearly represent each maintenance task category.
- Subtle, smooth transitions on loading, form submissions, and calendar navigations.
